Қўшимча

Файл очилмаса имзоланмаган файл ҳақида огоҳлантириш

Ўрнатувчида Apple ва Microsoft имзоси йўқ, шунинг учун тизим огоҳлантиради. Шу файлнинг ўзига рухсат беринг:

  • macOS 15 ва янгиси: «Готово / Done»ни босинг, кейин Тизим созламалари → Конфиденциальность и безопасность → пастда «Всё равно открыть / Open Anyway», паролни киритинг ва файлни яна очинг.
  • macOS 14 ва олдингилари: логотипни ўнг тугма билан босинг → «Открыть / Open» → яна «Открыть».
  • Windows: «Система Windows защитила ваш компьютер / Windows protected your PC» чиқса — «Подробнее / More info» → «Выполнить в любом случае / Run anyway».

Ишламаса ёки қотиб қолса тузатиш — тоза қайта ўрнатиш

Панел очилмаса, бўш ёки эски кўринса, лентадаги тугма йўқолса — ўрнатувчини очиб, Тузатишни танланг. Word очиқ бўлса, ўрнатувчи уни ёпишингизни кутади (ўзи ёпмайди).

  • Нима олинади (фақат «Ҳадислар»ники): Word'га уланган манифест, Office'даги шу қўшимча кеши, панелнинг Word ичидаги маълумотлари; Windows'да — реестрдаги ёзуви.
  • Ўчирилмайди: ҳаммаси заҳирага кўчирилади — Mac'да Корзинадаги Hadislar-backup-сана, Windows'да %TEMP%\Hadislar-backup-сана папкасига. Кейин қўшимча қайта ўрнатилади.
  • Тегилмайди: ҳужжатларингиз, бошқа қўшимчалар ва сайтлар, Scheherazade New шрифти.

Ойнасиз: Mac, Terminalда:

curl -fsSL https://hadis.abdulloh.org/mac.sh | bash -s -- --clean

Windows, PowerShellда (ёки Hadislar-Repair-Windows.bat):

irm https://hadis.abdulloh.org/win-clean.txt | iex
Браузер кенгайтмаси Chrome, Edge, Firefox

Ўрнатувчи кенгайтмани ўзи тайёрлайди ва браузернинг кенгайтмалар саҳифасини очади — у ерда бир марта улаш қолади. Қўлда:

Ishlamasa yoki qotib qolsa tuzatish — toza qayta oʻrnatish

Panel ochilmasa, boʻsh yoki eski koʻrinsa, lentadagi tugma yoʻqolsa — oʻrnatuvchini ochib, Tuzatishni tanlang. Word ochiq boʻlsa, oʻrnatuvchi uni yopishingizni kutadi (oʻzi yopmaydi).

  • Nima olinadi (faqat «Hadislar»niki): Word'ga ulangan manifest, Office'dagi shu qoʻshimcha keshi, panelning Word ichidagi maʼlumotlari; Windows'da — reyestrdagi yozuvi.
  • Oʻchirilmaydi: hammasi zaxiraga koʻchiriladi — Mac'da Korzinadagi Hadislar-backup-sana, Windows'da %TEMP%\Hadislar-backup-sana papkasiga. Keyin qoʻshimcha qayta oʻrnatiladi.
  • Tegilmaydi: hujjatlaringiz, boshqa qoʻshimchalar va saytlar, Scheherazade New shrifti.

Oynasiz: Mac, Terminalda:
