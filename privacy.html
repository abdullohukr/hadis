Сўнгги ўзгариш: 2026 йил 29 октябрь (лойиҳа)

Ҳадислар (hadis.abdulloh.org сайти, Microsoft Word учун қўшимча, браузер кенгайтмаси, Google Docs қўшимчаси ва WordPress плагини) ҳадисларни топиш ва уларни арабча матн, ўзбекча таржима ва тахриж билан ҳужжатларга қўйишга ёрдам беради. У шахсий маълумотларни йиғмасдан ишлайди.

Ушбу сайтдаги ўзбекча таржима ва тахриж лойиҳа муаллифи томонидан тайёрланган; арабча матнларнинг манба нашрлари Манбалар саҳифасида кўрсатилган. Алоқа: hadis@abdulloh.org

Нималар йиғилмайди

  • Ҳисоб, кириш, исм ёки электрон почта йўқ.
  • Ҳужжатларингиз мазмуни ўқилмайди, сақланмайди ва юборилмайди. Панель фақат сиз танлаган матнни курсор турган жойга ёзади.
  • Реклама, кузатув ва аналитика йўқ.

Қурилмангизда сақланадиган маълумотлар

Панель браузернинг маҳаллий хотирасида (Word'да — қўшимчанинг ўз хотирасида) қуйидагиларни сақлайди. Улар қурилмангиздан ҳеч қаерга чиқмайди; сайт маълумотларини тозалаш билан ўчирса бўлади («Созламаларни тиклаш» фақат созламаларни ўчиради):

  • hadis-settings — созламалар: ёзув (кирилл ёки лотин), мавзу, нима қўйилиши, шрифтлар ва ўлчамлар;
  • hadis-history — сўнгги 50 та қўйилган ҳадис (китоб ва ҳадис рақами, танланган сўзлар оралиғи, матн боши, вақт);
  • hadis-favorites ва hadis-basket — юлдузча қўйилган (500 тагача) ёки саватга солинган (100 тагача) ҳадислар, шу шаклда;
  • hadis-recent — сўнгги қидирув сўровлари (таклиф учун);
  • hadis-reload (сеанс хотираси) — ўзи қайта юкланганидан кейинги нашр рақами, саҳифа ёпилгунча.

Интернетсиз ишлаш учун браузер сайт саҳифалари, маълумот файллари ва шрифтларнинг нусхасини кэшда сақлайди.

Тармоқ сўровлари

Ҳадис матнлари, қидирув индекси ва шрифтлар шу сайтнинг файллари (data, search, fonts папкалари); панель уларни фақат hadis.abdulloh.org'дан юклайди, ҳадисларни кўрсатиш учун бошқа серверларга мурожаат қилмайди. Янги нашрни билиш учун version.json'ни ўқийди. Microsoft Word ичида панель Microsoft'нинг Office JavaScript кутубхонасини appsforoffice.microsoft.com'дан юклайди. Қидирув сўровларингиз қурилмангизда ишланади ва бизга юборилмайди.

Ҳар қандай сайтдаги каби, сайтни жойлаштирган сервер файлни етказиш учун зарур техник маълумотни (IP манзил, браузер тури) олади ва одатий сервер журналида сақлаши мумкин. Биз уни ҳеч кимни аниқлаш учун ишлатмаймиз. Сайт GitHub Pages орқали тақдим этилади.

Браузер кенгайтмаси, Google Docs ва WordPress

  • Браузер кенгайтмаси (Chrome, Edge, Firefox): панелни браузернинг ён панелида кўрсатади. Фақат «Қўйиш» босилганда танланган матнни жорий саҳифадаги курсор турган майдонга қўяди; саҳифалар мазмунини ўқимайди ва юбормайди, кирган сайтларингизни кузатмайди, бошқа ойналарга кира олмайди. Ўзининг кичик созламаларини (таҳрирлагичларга қўйиш усули, охирги қўйилган ҳадис) кенгайтма хотирасида сақлайди.
  • Google Docs қўшимчаси: фақат очилган ҳужжатга кира олади ва фақат танланган матнни курсордан кейин қўйиш учун.
  • WordPress плагини: панель фақат ёзув таҳрирлагичида, ёзаётган одам учун юкланади. Қўйилган матн ёзувда оддий HTML сифатида сақланади, шунинг учун сайт меҳмонлари бизнинг сайтга уланмайди.

Болалар

Панель ҳеч кимдан, шу жумладан болалардан ҳам шахсий маълумот йиғмайди.

Ўзгаришлар ва алоқа

Сиёсат ўзгарса, янги нусха янги сана билан шу саҳифада эълон қилинади. Саволлар: hadis@abdulloh.org.

Soʻnggi oʻzgarish: 2026 yil 29 oktabr (loyiha)

Hadislar (hadis.abdulloh.org sayti, Microsoft Word uchun qoʻshimcha, brauzer kengaytmasi, Google Docs qoʻshimchasi va WordPress plagini) hadislarni topish va ularni arabcha matn, oʻzbekcha tarjima va taxrij bilan hujjatlarga qoʻyishga yordam beradi. U shaxsiy maʼlumotlarni yigʻmasdan ishlaydi.

Ushbu saytdagi oʻzbekcha tarjima va taxrij loyiha muallifi tomonidan tayyorlangan; arabcha matnlarning manba nashrlari Manbalar sahifasida koʻrsatilgan. Aloqa: hadis@abdulloh.org

Nimalar yigʻilmaydi

  • Hisob, kirish, ism yoki elektron pochta yoʻq.
  • Hujjatlaringiz mazmuni oʻqilmaydi, saqlanmaydi va yuborilmaydi. Panel faqat siz tanlagan matnni kursor turgan joyga yozadi.
  • Reklama, kuzatuv va analitika yoʻq.

Qurilmangizda saqlanadigan maʼlumotlar

Panel brauzerning mahalliy xotirasida (Word'da — qoʻshimchaning oʻz xotirasida) quyidagilarni saqlaydi. Ular qurilmangizdan hech qayerga chiqmaydi; sayt maʼlumotlarini tozalash bilan oʻchirsa boʻladi («Sozlamalarni tiklash» faqat sozlamalarni oʻchiradi):

  • hadis-settings — sozlamalar: yozuv (kirill yoki lotin), mavzu, nima qoʻyilishi, shriftlar va oʻlchamlar;
  • hadis-history — soʻnggi 50 ta qoʻyilgan hadis (kitob va hadis raqami, tanlangan soʻzlar oraligʻi, matn boshi, vaqt);
  • hadis-favorites va hadis-basket — yulduzcha qoʻyilgan (500 tagacha) yoki savatga solingan (100 tagacha) hadislar, shu shaklda;
  • hadis-recent — soʻnggi qidiruv soʻrovlari (taklif uchun);
  • hadis-reload (seans xotirasi) — oʻzi qayta yuklanganidan keyingi nashr raqami, sahifa yopilguncha.

Internetsiz ishlash uchun brauzer sayt sahifalari, maʼlumot fayllari va shriftlarning nusxasini keshda saqlaydi.

Tarmoq soʻrovlari

Hadis matnlari, qidiruv indeksi va shriftlar shu saytning fayllari (data, search, fonts papkalari); panel ularni faqat hadis.abdulloh.org'dan yuklaydi, hadislarni koʻrsatish uchun boshqa serverlarga murojaat qilmaydi. Yangi nashrni bilish uchun version.json'ni oʻqiydi. Microsoft Word ichida panel Microsoft'ning Office JavaScript kutubxonasini appsforoffice.microsoft.com'dan yuklaydi. Qidiruv soʻrovlaringiz qurilmangizda ishlanadi va bizga yuborilmaydi.

Har qanday saytdagi kabi, saytni joylashtirgan server faylni yetkazish uchun zarur texnik maʼlumotni (IP manzil, brauzer turi) oladi va odatiy server jurnalida saqlashi mumkin. Biz uni hech kimni aniqlash uchun ishlatmaymiz. Sayt GitHub Pages orqali taqdim etiladi.

Brauzer kengaytmasi, Google Docs va WordPress

  • Brauzer kengaytmasi (Chrome, Edge, Firefox): panelni brauzerning yon panelida koʻrsatadi. Faqat «Qoʻyish» bosilganda tanlangan matnni joriy sahifadagi kursor turgan maydonga qoʻyadi; sahifalar mazmunini oʻqimaydi va yubormaydi, kirgan saytlaringizni kuzatmaydi, boshqa oynalarga kira olmaydi. Oʻzining kichik sozlamalarini (tahrirlagichlarga qoʻyish usuli, oxirgi qoʻyilgan hadis) kengaytma xotirasida saqlaydi.
  • Google Docs qoʻshimchasi: faqat ochilgan hujjatga kira oladi va faqat tanlangan matnni kursordan keyin qoʻyish uchun.
  • WordPress plagini: panel faqat yozuv tahrirlagichida, yozayotgan odam uchun yuklanadi. Qoʻyilgan matn yozuvda oddiy HTML sifatida saqlanadi, shuning uchun sayt mehmonlari bizning saytga ulanmaydi.
